PVCollada validation resources

The COLLADA XSD imports the W3C XML namespace schema and the optional MathML
formula namespace by remote URL. xml.xsd is vendored from W3C. S3 does not
interpret COLLADA formula/kinematics payloads, so a local namespace declaration
for the referenced MathML `math` element prevents runtime network resolution;
formula content remains outside the supported geometry contract.
